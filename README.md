<details open>
  <summary><b>🤖 Sobre o Projeto</b></summary><br/>
  
  <p align="justify">
    Este projeto consiste no desenvolvimento e implementação de uma <b>Garra Robótica</b> articulada, projetada para manipulação e preensão de objetos com precisão. O sistema integra projeto mecânico (peças impressas em 3D), circuitos eletrônicos de potência e controle de servomotores programados em C++/Arduino.
  </p>

  <h3>🎯 Principais Funcionalidades</h3>
  <ul>
    <li><b>Articulação Multieixo:</b> Movimentação de base, elevação e abertura/fechamento da garra.</li>
    <li><b>Controle Suave:</b> Algoritmo de atenuação de aceleração para evitar solavancos nos servos.</li>
    <li><b>Interface de Controle:</b> Operação via potenciômetros / joystick / app bluetooth (escolha o seu modo).</li>
    <li><b>Estrutura Leve e Modular:</b> Peças projetadas para fabricação digital em impressora 3D (PLA/PETG).</li>
  </ul>
</details>
